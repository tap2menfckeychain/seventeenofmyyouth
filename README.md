# Nhật kí thanh xuân · Seventeen
Cuốn nhật kí tĩnh (HTML/CSS/JS), không cần cài đặt.
- Sửa lời nhắn: mở `index.html`, tìm `CHỈNH SỬA TẠI ĐÂY`.
- Muốn thêm câu thật của thành viên: dán vào `said`, ghi nguồn vào `by`.
- Thêm ảnh: bỏ vào `images/` rồi thêm một mục vào mảng `PHOTOS`.
- Đổi nhạc: thay `music/nhac.mp3`.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
